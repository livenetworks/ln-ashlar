# Ashlar — заклучок за дизајнот и план до финалната верзија

Бренч: `design/ui-refresh` · Ажурирано: 2026-10-29

## 1. Заклучок

**Проблемот не е во токените, туку во три нивоа над нив.**

Ashlar има добра основа: сè е во токени, има теми, густини, mixins. Soft
темата веќе има речиси исти вредности како МЕПСО концептот (радиуси
6/10/16/22, Plus Jakarta Sans, иста позадина `#f1f5f9`). Сепак архитектот
и product owner-от не гледаат разлика. Причините, по тежина:

1. **Default изгледот е стар.** Библиотеката без `data-theme` е густата
   DocuFlow верзија: Inter, 14px, 36px контроли, индиго акцент. Soft е
   само опција, вклучена во демото. Секој нов проект почнува со стариот изглед.
2. **Shell-от нема карактер.** Бел sidebar, ситен сив текст во менито,
   икона само на една ставка, бледа активна ставка, topbar со алатки за
   развој. МЕПСО го добива целиот впечаток од темниот бренд sidebar,
   иконите, бројачите и главното копче во topbar-от.
3. **Демото е каталог, не производ.** Првата страна покажува „Modal“ со
   две копчиња и „Tabs“ со црвена debug рамка. МЕПСО покажува реален
   dashboard: бројки, табела со статуси, табови, брза форма.
4. **Компонентите немаат „тон“.** Сите stat картички се исти (една боја),
   табовите се само подвлечени, нема сегментирани табови во панели, нема
   бројачи во навигацијата.

Досегашните поправки (полиња, висини, контраст, рамки) се точни и остануваат,
но се „невидливи“ на првиот екран. Тие се основата, не впечатокот.

**Што земаме од МЕПСО:** композиција, тон по боја, темен sidebar, тежина на
типографијата, реалистична содржина.
**Што не земаме:** нивните бои за статус (2.3–2.9:1, под WCAG AA), hex бои
наместо токени, `style.display` од JS, класи за сè.

## 2. Што е направено (на овој бренч)

**Нов default изглед (v3).** Без `data-theme` / `data-density` библиотеката
сега изгледа модерно: Plus Jakarta Sans, сина акцентна боја, slate палета,
радиуси 6/10/16/22, меки сенки, 16px текст и 44px контроли.
Стариот изглед е зачуван како `data-theme="classic"` + `data-density="compact"`
(DocuFlow го користи).

**Shell.**
- `data-theme="brand"` — темен navy регион; работи и само на sidebar-от
  (`<aside data-theme="brand">`), како кај МЕПСО. Default sidebar останува светол.
- Теми на дел од страната: `data-theme` работи на било кој елемент.
- Навигација: икона на секоја ставка, uppercase наслови на секции,
  `.nav-count` бројачи, појасна активна ставка.
- Footer без „status bar“, проѕирни scrollbar ленти.

**Компоненти.**
- Stat картичка со тон (`data-ln-stat-card="success"` …) и икона.
- Сегментирани табови (`@include tabs-nav-segmented`).
- Panel header со наслов + опис (`<hgroup>`), без сив „title bar“.
- Форми: бели полиња, видлив focus, иста висина на сите контроли
  (36 / 44 / 54 px), растојание меѓу полиња.
- Badge не се прекршува во два реда; modal со поголем радиус.

**Пристапност.** Статусни бои ≥ 4.8:1; dark тема со светол accent (8:1)
и темен текст на полни копчиња; hover секогаш се оддалечува од површината.

**Демо.** Нов Dashboard по моделот на МЕПСО (бројки со тон, регистар со
сегментирани табови, брза форма, активности). Старата почетна е преместена
во „Getting started“. Debug рамките се исклучени. Копче во topbar-от за
светол / brand sidebar.

Детали: `docs/css/soft-design-review.md`, `docs/css/theming.md`,
`docs/css/density.md`.

## 4. Донесени одлуки

| # | Прашање | Одлука |
|---|---|---|
| 1 | Soft да стане default изглед? | Да; стариот е `classic`. |
| 2 | Default густина? | `comfortable`; `compact` е опција. |
| 3 | Sidebar default? | Светол; темен со `data-theme="brand"`. |
| 4 | Обем? | Фази 1–4 во овој круг. |

**Влијание на постоечки проекти:** секој проект што не поставува
`data-theme` / `data-density` ќе го добие новиот изглед и поголемата
густина. За да остане како порано: `<html data-theme="classic" data-density="compact">`.
