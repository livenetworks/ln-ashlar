# Skin: `data-skin="hairline"`

Flat, quiet, fast structural skin. Token rebinds only, in one new block in
`theme/config/_theme.scss`, plus the enumeration sites that already list
`outline`. No new tokens, no mixin/component/markup changes.

## Findings that shape the plan (all verified against source)

- Cascade order: `[data-skin]` (0,1,0) ties with `_tokens.scss` `:root` (0,1,0)
  for `--transition-*` / `--easing-spring`. `theme/ln-ashlar-theme.scss`,
  `-landing.scss`, `-relaxed.scss` all `@use 'config/tokens'` before
  `'config/theme'`, so the skin wins by source order. (Outline's shadow rebinds
  do not prove this: the shadow defaults live in `:where()`.) Acceptance step 7
  checks the compiled order.
- `--easing-spring` is read once: `theme/config/mixins/_nav.scss:209`
  (`transform 220ms var(--easing-spring)`). Custom properties inherit, so the
  rebind reaches it.
- `--transition` is declared at `_tokens.scss:245` as `var(--transition-base)`;
  re-declaring it in the skin block makes it resolve against the skin's base.
- Shadow set: `--shadow-overlay` is `var(--shadow-xl)` and `--shadow` is
  `var(--shadow-resting)`, both re-derived on `[data-skin]` elements by the
  `:where([data-skin])` block in `_palette.scss:228-242`, so outline's set
  covers them. Copy it verbatim.
- Transition tokens in `_tokens.scss:72-74` use the literal curve
  `cubic-bezier(0.4, 0, 0.2, 1)`, so the skin uses the same literal.
  `--easing-spring` is an alias of the standard curve, so it uses
  `var(--easing-standard)` (resolves at html, which
  `tests/brand-theme-cascade.test.js` Root-Resolvability allows).
- `docs-mcp/css/theming.md` lists skins only inside a generated, fenced table
  (`scripts/sync-css-tokens.mjs:294`, regenerated by `npm run build`). That
  table lists `glass` and does NOT list `outline`, so by the "alongside
  outline" rule it gets no hairline row. Reported, not changed.

today `glass` and `outline` exist as blocks at the end of

elevation shadows), quiet (default borders untouched), fast (shorter
transitions, no overshoot). It is token rebinds only. The demo skin picker and
a few docs that enumerate skins must list it.

```scss
	--shadow-md: none;
	--shadow-lg: none;

	--shadow-2xl: none;

	--transition-base: 0.15s cubic-bezier(0.4, 0, 0.2, 1);
	--transition-slow: 0.2s cubic-bezier(0.4, 0, 0.2, 1);
	// Re-declared: var() resolves where declared, so :root's copy would keep 0.25s.
	--transition: var(--transition-base);
	--easing-spring: var(--easing-standard);
}
```
