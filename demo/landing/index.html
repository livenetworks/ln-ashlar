Frequently Asked Questions

Got questions? We've got answers

Explore answers to common questions about ln-ashlar's architecture and usage.

  • How does the presentation CSS differ from the admin CSS?

    The admin CSS is optimized for data density, complex data tables, and application shells with compact 14px body text. The presentation CSS is designed for high-impact marketing pages, featuring fluid clamp() display typography, ambient lighting glows, bento grids, and high-conversion CTAs.

  • Can I use Ashlar interactive components on my landing page?

    Yes! The presentation bundle includes full styling and support for Ashlar's vanilla JS components such as accordions (like this FAQ), modals for lead generation, tabs for pricing periods, and dropdown menus.

  • How do Scoped Mode Islands work?

    Any HTML container can declare data-mode="dark" or data-theme="violet". Ashlar's derivation engine automatically calculates all surface colors, contrasts, and border tokens for that container and its descendants without affecting the rest of the page.

  • Are external icon libraries or frameworks required?

    No external frameworks are required. Ashlar uses vanilla HTML5, modern CSS custom properties, and lightweight vanilla JS. The built-in ln-icon component seamlessly bundles and manages SVG sprites.
