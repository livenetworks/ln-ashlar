Overview & Philosophy

ln-repeater is applied to a container via data-ln-repeater="name" wrapping a list ([data-ln-repeater-list]), add/remove triggers ([data-ln-repeater-add], [data-ln-repeater-remove]), and an HTML <template> defining a single row. It clones rows from the template, substitutes {index} / {index1} placeholders, enforces data-ln-repeater-min / max bounds via native disabled state, and hydrates rows from ln-fill payloads.

The component knows nothing about what inputs live inside a row — a single text input, a translatable multi-language group, or a multi-column line-item fieldset all use the exact same primitive. Everything else composes orthogonally: add data-ln-sortable to the list for drag-and-drop reordering, wrap the form in data-ln-translations for inline side-by-side translations, and drive Edit/Create modals with ln-fill.

For the full guide see the ln-repeater README.

            Attributes, API & Events

            Attributes

            AttributeOn elementDefaultDescription
            data-ln-repeaterRoot""Mounts the repeater. Optional value names the <template data-ln-template> and the ln-fill array key.
            data-ln-repeater-minRoot0Minimum rows. Auto-seeds on init when empty and disables remove buttons at count <= min.
            data-ln-repeater-maxRootInfinityMaximum rows. Disables internal/external add triggers once reached.
            data-ln-repeater-reindexRootfalseSequentially re-numbers {index} / {index1} attributes on remove or ln-sortable:reordered.
            data-ln-repeater-list<ul> / <ol>—Container where repeated rows are appended.
            data-ln-repeater-itemRow—Marks an individual repeated row (added automatically to cloned rows).
            data-ln-repeater-add<button type="button">—Internal button that appends a new row from the template.
            data-ln-repeater-add-for<button type="button">—External trigger referencing a repeater root by id.
            data-ln-repeater-remove<button type="button">—Per-row button that removes its owning item.

            Instance API

            const el = document.querySelector('[data-ln-repeater]');
el.lnRepeater.add({ label: 'Linux' });  // appends & populates row
el.lnRepeater.remove(0);                // removes row by index or element
el.lnRepeater.clear();                  // clears down to min (or { force: true })
el.lnRepeater.items;                    // HTMLElement[]
el.lnRepeater.count;                    // number
