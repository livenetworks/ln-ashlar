Overview

data-ln-websocket-connector opens a WebSocket inside a ln-data-coordinator. Server pushes land in the store, and every bound table refreshes. Beside a REST connector it only delivers live changes; on its own it carries reads, writes and pushes.

Both examples talk to one local mock. Start it, then reload this page:

php demo/websocket/ws-mock.php

It listens on port 8090, changes a random task every few seconds, and pushes every write to every open socket — a task added in one example appears in the other.

Connection status is not an attribute. The connector announces it with :connecting, :connected and :disconnected; this page listens and colours the chip.
