ln-key (Keyboard Shortcuts)

Declaratively binds keyboard shortcuts to native click() or focus() behavior on target DOM elements. Supports modifier combinations (Ctrl, Alt, Shift, Meta), target redirection, input protection, and declarative shortcut mapping via data-ln-key-for.

1. Direct Action Hotkeys (data-ln-key)

Attaching data-ln-key directly to buttons or links triggers their native click() when the specified key combination is pressed.

2. Target Focus & Input Redirection (data-ln-key-target)

Use data-ln-key-target="#id" to route a shortcut to another DOM element (e.g. focusing a search bar or filter dropdown).

Pressing Ctrl+K automatically focuses this input box.

3. Declarative Shortcut Map (data-ln-key-map & data-ln-key-for)

Combine a container's data-ln-key-map="Ctrl+Shift" modifier context with individual <kbd data-ln-key-for="#target">Key</kbd> elements to generate composed shortcuts automatically without duplicate attribute boilerplate.

Bulk Export Menu (Parent Modifier: Ctrl+Shift)

Press Ctrl+Shift+C, Ctrl+Shift+P, or Ctrl+Shift+J to trigger these actions.

4. Input Protection & Input Override (data-ln-key-allow-input)

By default, ln-key ignores single-character hotkeys when the user is typing inside text inputs, textareas, or contenteditables. Use data-ln-key-allow-input to explicitly permit submission shortcuts (like Ctrl+Enter).

Pressing hotkeys like Alt+N or Esc while typing in this box will NOT fire background actions.

Pressing Ctrl+Enter inside this comment box submits the form directly.

5. Keycap Typography & UI Styling Reference

All <kbd> elements are automatically styled via theme/base/_typography.scss to give a clean, elevated keycap appearance across light and dark themes.
