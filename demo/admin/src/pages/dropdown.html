Overview & Philosophy

A dropdown menu is one of the most common layout controls in web applications. While simple on the surface, a premium dropdown menu requires robust engineering: it must close when the user clicks outside, close on viewport resizes, promote to the browser's top layer to escape parent stacking contexts (preventing overflow: hidden clippings), provide full ARIA APG keyboard roving navigation, and position itself dynamically to fit the viewport.

In ln-ashlar, we solve this elegantly. ln-dropdown is a coordinator wrapper that layers this menu-grade behavior on top of a standard ln-toggle instance. The dropdown component does not re-implement state; it delegates 100% of its open/closed state management to the underlying toggle primitive, adding top-layer popover promotion, keyboard roving focus, click-outside listeners, and positioning math on top.

The Dropdown Doctrine

A dropdown does not own its state. The open/closed state lives entirely in the data-ln-toggle attribute of the inner menu. Click-outside rules, Escape keypresses, and resize handlers close the menu simply by writing data-ln-toggle="close" back to the menu. The observer on the toggle runs the close pipeline, which the dropdown coordinates. The HTML attribute is the sole contract.

Top-Layer Promotion & Positioning

When a dropdown menu is activated, ln-dropdown promotes the menu element to the top layer using the native Popover API (popover="manual", showPopover()) to prevent clipping under scrollable containers or nested cards. It then measures the trigger element and matches its position right-aligned below the trigger (or according to data-ln-dropdown-position). It automatically flips above if vertical space is restricted, and removes positioning styles when closed.

For the complete developer reference, see the ln-dropdown README and the architecture reference.

Example 1 — Basic Dropdown (with ARIA Keyboard Navigation)

Click the button or press ArrowDown on it to open. Use ArrowDown, ArrowUp, Home, and End to navigate through the menu items. Press Escape to close and return focus to the trigger.

Example 2 — Configurable Placement

Use data-ln-dropdown-position to specify the desired alignment (e.g. bottom-start for left-aligned buttons).

Dependencies

Dropdown depends on ln-toggle. ln-toggle must be loaded before dropdown.
