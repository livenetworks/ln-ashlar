Overview & Philosophy

When an action requires immediate user attention, data input, or a high-context confirmation, displaying a modal window is the standard UX pattern. However, a premium modal is more than just a centered dialog box; it requires strict accessibility, focus traps, and scrolling behavior controls.

In ln-ashlar, this follows the Three-Layer Architecture: ln-modal is a Layer 1 Simple Component that manages the native <dialog> overlay state, scroll locking, and accessibility, while ln-modal-coordinator is the Layer 2 Coordinator that handles triggers (data-ln-modal-for), hash navigation (#modalId), data populating (ln-fill), and form auto-closing (ln-form:success).

The Modal & Coordinator Doctrine

The contract is absolute: ln-modal (on <dialog data-ln-modal>) manages ONLY the binary overlay state. ln-modal-coordinator (placed directly on <dialog data-ln-modal-coordinator>) acts as the Layer 2 Coordinator on the dialog itself, orchestrating its inner form (<form data-ln-form>), triggers (data-ln-modal-for), deep links (#modalId:param), and auto-closing on ln-form:success.

Focus Trapping & Accessibility (WAI-ARIA)

A modal must be isolated. When open, ln-modal enforces the following behavior:

  • Native Focus Trap: Tabbing cycles keyboard focus strictly inside the native <dialog> when opened via showModal().
  • Background Scroll Lock: Opening a modal suppresses background scrolling by applying the ln-modal-open class to <body>.
  • Escape Key Dismissal: Pressing ESC routes through the attribute synchronizer to ensure before-close lifecycle validation always runs.
  • Focus Return: When closed, keyboard focus returns precisely to the trigger element that launched it.

For the complete developer reference, see the ln-modal README and the ln-modal-coordinator spec.

Hash addressing & coexistence

Demonstrates codec isolation: ln-tabs and ln-modal share the same URL hash using the ln-core hash codec. Each component reads and writes ONLY its own namespace segment — foreign segments are preserved on every write. The modal's namespace is its id (demo-hash-modal).

Manual tests:

  1. Click Edit #5, switch to the Members tab. The URL becomes #demo-hash-modal:5&demo-tab:members, the modal STAYS open, and the Title field is filled by the ln-modal-coordinator.
  2. Reverse order (regression direction): switch to the Members tab FIRST, then click Edit #5. The URL becomes #demo-tab:members&demo-hash-modal:5 and the tab STAYS on Members — the modal anchor click MERGES its segment instead of replacing the whole fragment.
  3. Reload with #demo-tab:members&demo-hash-modal:42 in the URL. The Members tab should be active AND the modal open with Title "Internal audit log" filled.
  4. With the modal open, press Back → modal closes, tab state intact.
