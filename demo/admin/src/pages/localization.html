Localization (Date & Number)

Overview & Philosophy

Formatting numbers, currencies, and dates across global enterprise applications is traditionally fraught with heavy, bloated third-party JavaScript dependencies. These often introduce slow parse times, bundle inflation, and conflicting client/server date parsing logic.

In ln-ashlar, this is resolved by ln-number and ln-date — two zero-dependency, high-performance form input enhancers. Operating on standard HTML inputs, they provide real-time, locale-aware presentation formatting while preserving pristine, raw machine-readable data payloads (numbers and ISO 8601 strings) for backend form submissions via automatically managed hidden inputs.

The HTML-First Localization Doctrine

Components do not implement complex custom calendar engines or numerical calculators. They progressively enhance standard HTML5 <input type="number">, <input type="date">, and semantic tags (<time>, <strong>, <td>). Formatting and locale rules are offloaded directly to the browser's native Intl.NumberFormat and Intl.DateTimeFormat engines, with instant reactive updates when the parent lang attribute changes.

Key Architectural Advantages

  1. Reactive Locale Cascading: Both components listen for BCP 47 language updates on parent scopes via MutationObserver. Changing the lang attribute instantly triggers a real-time re-format across all child inputs and semantic elements with zero page reload.
  2. Two-Way Value Interception: Overrides native DOM value property descriptors. Reading input.value or assigning programmatic values automatically synchronizes both the visible formatted input and the underlying hidden payload field.
  3. Native Platform Integration: ln-date connects to native browser date pickers (showPicker()) and supports resilient manual typing on blur with smart 2-digit year pivots. ln-number preserves cursor offsets during active typing.
  4. Semantic Accessibility: Format static or dynamic data using standard HTML5 tags (<time datetime="...">, <strong data-ln-number>) to preserve machine readability for screen readers while presenting human-friendly localized formats.

For complete technical specifications, see the ln-number documentation and ln-date documentation.

Attributes Reference

ln-number Attributes

AttributeOn ElementDescription
data-ln-number<input>, <span>, <td>Enables locale-aware number formatting. On inputs, initializes the component.
data-ln-number-decimals="N"<input>, text tagsLocks maximum permitted decimal places (e.g. 2 for currency).
data-ln-number-min="N"<input>Minimum numeric threshold (clamped during input).
data-ln-number-max="N"<input>Maximum numeric threshold (clamped during input).

ln-date Attributes

AttributeOn ElementDescription
data-ln-date="style|pattern"<input>, <time>Keyword (short, medium, long) or pattern (e.g. dd.MM.yyyy, MMMM yyyy). Defaults to medium.
data-ln-date-label="Text"<input>Accessible aria-label override for the calendar picker trigger button.
data-ln-fill-as="prop"<input>Custom field identifier for integration with ln-fill coordinators.
data-ln-date-dict="lang"<ul hidden>Declarative HTML dictionary container for language fallbacks (read via buildDict).

Number Formatting — ln-number

Real-time locale-aware number formatting. The component creates a hidden input for form submission and formats the visible input with thousand separators.

Non-Input Text Element Formatting (<strong>, <td>)

ln-number can also format static or dynamic text elements directly in HTML according to the active locale.

Raw Text standard: 1234567.89
Result: 1234567.89
Attribute value + 2 decimals: 5000
Result: €5000

Date Formatting — ln-date

Locale-aware date formatting with native browser picker. The component creates a hidden input for form submission and formats the visible input using Intl.DateTimeFormat or custom patterns.

  • јануари, февруари, март, април, мај, јуни, јули, август, септември, октомври, ноември, декември
  • јан, фев, мар, апр, мај, јун, јул, авг, септ, окт, ноем, дек

Semantic Text Element Formatting (<time>, <td>)

For semantic HTML5 accessibility, use <time datetime="..."> elements with data-ln-date.

Medium format: <time datetime="2026-07-25">
Result: 2026-07-25
Long format: <time datetime="2026-07-25">
Result: 2026-07-25
Custom pattern: dd.MM.yyyy
Result: 2026-07-25
