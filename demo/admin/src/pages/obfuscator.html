Overview

The ln-obfuscator component is an autonomous anti-crawler utility. It prevents automated email harvesters, telephone scrapers, and bot crawlers from extracting raw contact info and proprietary text from static HTML responses.

It can be placed on any HTML element — plain text spans, paragraphs, table cells, or anchor tags (<a>). Upon boot, it traverses all child text nodes and automatically deobfuscates them in place. For links, it simultaneously deobfuscates the href attribute (e.g. mailto: or tel: targets).

AttributeElementDefaultDescription
data-ln-obfuscator Any element 13 Triggers deobfuscation. Optional integer sets ROT shift (1–25). If empty, defaults to ROT13.
data-ln-obfuscator-codec Any element "rot" Selects cipher algorithm: "rot" (letters/digits Caesar), "base64" (universal UTF-8), or "xor" (keyed symmetric).
data-ln-obfuscator-key Any element "ln-ashlar" Custom secret key for "xor" codec. Providing this attribute automatically activates the XOR codec.

Safe Text-Node Traversal (Preserves Child HTML)

Unlike naive innerHTML replacers that corrupt HTML tag names (e.g. turning <strong> into <fgebat>), ln-obfuscator walks individual text nodes with TreeWalker. Child formatting tags remain 100% intact:

Authored: <div data-ln-obfuscator>Grkg jvgu <strong>obyq</strong> naq <em>vgnyvp</em>...</div>
