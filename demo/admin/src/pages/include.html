Overview & How It Works

The ln-include component is applied to any HTML template element via <template data-ln-include="/path.html"> to load template contents asynchronously from external files. During the initial application boot, it automatically delays page-wide component sweeps until all declared templates have finished loading, preventing empty-state and layout flicker.

Multiple templates pointing to the same external URL automatically share a single fetch promise to eliminate redundant network requests. Once retrieved, the HTML is injected into the template's .content document fragment and an ln-include:loaded event is dispatched, allowing external templates (such as table rows or empty states) to be reused across pages with zero client-side view logic.
